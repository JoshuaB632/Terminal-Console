### Project Overview
This is a small passion project to create a gamified version of a terminal to be used in a future video game. The console is designed to have a retro feel, stating memory and disc usage, dealing with physical insertable drives, and overall being a very barebones system. Despite the retro feel, the console is also designed to be easy to use for players with no real experience using similar systems. The console is also being designed to fit the needs of the game, as a main lore and information destination as well as a crucial part of mid to late game upgrades, automation, and tech.

10/19: As of now the console is under major reworks with the goals of condensing/simplifying operations and effectively planning for future implementations.
